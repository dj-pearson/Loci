## Important Context for Ralph Iterations

### Project Overview
Loci is a voice-first iOS app (SwiftUI, iOS 17+) that pins voice notes to GPS coordinates with proximity-triggered push notifications and family sharing. Backend is self-hosted Supabase with PostGIS on Contabo/Coolify. Marketing site on Cloudflare Pages (Astro).

### Tech Stack
- **iOS**: Swift 5.9+, SwiftUI, SwiftData, CoreLocation (CLMonitor), AVFoundation, Apple Speech, MapKit, WidgetKit, RevenueCat, supabase-swift, TelemetryDeck
- **Backend**: PostgreSQL 15+ with PostGIS, Supabase Auth/Storage/PostgREST, Node.js 20 + Hono (Docker sidecar)
- **Web**: Astro + Tailwind on Cloudflare Pages
- **CI/CD**: GitHub Actions, Fastlane, SwiftLint

### Architecture
- MVVM with @Observable classes (not Combine ObservableObject)
- SwiftData for local persistence (not Core Data)
- Offline-first: full functionality without network, sync is additive
- CLMonitor for geofencing (iOS 17+ API, not legacy CLLocationManager regions)
- 20-geofence iOS limit managed by nearest-rotation strategy

### Key Decisions
- Apple Speech over Whisper (free, on-device, private)
- PostGIS over CloudKit (existing infra, spatial queries, household sync)
- M4A over WAV (100KB/30s vs 5MB/30s)
- CLMonitor over legacy geofence API (better reliability)
- RevenueCat for subscriptions (free under $2.5K MRR)

### Monetization Tiers
- Free: 10 loci, no sharing, no AI, basic map
- Premium ($3.99/mo, $29.99/yr): Unlimited, AI, sync, widget, search. 7-day trial.
- Family ($5.99/mo, $44.99/yr): All Premium + household sharing (up to 6). Host needs Family plan.
- Lifetime: $59.99 individual, $89.99 family (launch promo: $39.99/$59.99)

## Notes for Ralph Iterations

1. **iOS Build**: Use `xcodebuild -scheme Loci -sdk iphonesimulator` for build verification.
2. **SwiftData requires iOS 17+**: All @Model classes use SwiftData, not Core Data.
3. **CLMonitor is iOS 17+**: Do not use legacy CLLocationManager region monitoring.
4. **@Observable not ObservableObject**: Use the Observation framework, not Combine.
5. **No Whisper API in V1**: Transcription is Apple Speech framework only.
6. **Offline-first**: Every feature must work without network. Sync is additive.
7. **Free tier enforcement**: Check SubscriptionTier before premium features.
8. **Audio format**: M4A/AAC at 64kbps mono, ~100KB per 30 seconds.
9. **Geofence limit**: iOS enforces max 20 CLCircularRegions per app.
10. **The edge functions are Node.js/Hono in Docker, NOT Supabase Edge Functions (Deno).**
11. **Android Build**: Use `cd android && ./gradlew assembleDebug` for build verification.
12. **Android minSdk 26**: Supports Android 8.0+ (Oreo) for Instant, notification channels, and biometric APIs.
13. **Android geofence limit is 100**: Android allows 100 geofences vs iOS 20.
14. **Hilt for DI**: All ViewModels use @HiltViewModel, all services injected via @Inject constructor.
15. **Room, not SQLite directly**: All local persistence through Room DAOs with Flow-based reactive queries.
16. **Jetpack Compose, not XML layouts**: All UI is declarative Compose with Material 3.
17. **EncryptedSharedPreferences**: All auth tokens and sensitive data use AndroidX Security crypto.
18. **Same Supabase backend**: Android shares the same PostgreSQL/PostGIS backend as iOS — no backend changes needed.
